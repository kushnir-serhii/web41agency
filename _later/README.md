# Відкладено: інтерактивні ефекти (як на joie.com.ua)

Пріоритет зараз — контент і тексти. Повернутися після цього.

- **Spotlight glow** на картках (Services → features): `SpotlightList.tsx` + CSS-клас `.spotlight` (radial-gradient з `--spot-x/--spot-y`, лише для миші).
- **Dot field** (canvas) у фоні Hero: `DotField.tsx`. Цикл анімації працює лише під час руху; на тачі й з reduced motion — статична сітка.
- **3D-модель** (Three.js): тільки десктоп і з відкладеним завантаженням, щоб не просіла швидкість.

Файли тут не підключені до сайту.
